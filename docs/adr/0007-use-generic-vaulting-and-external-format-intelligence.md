# Use generic vaulting and external Format Intelligence

Every accepted format receives a generic baseline of identity, Artifact, digest, versioned metadata, and manual relationship support. Deeper extraction, structure, preview, or conversion uses closed-file parsers or standalone/headless tools outside design software; each exact adapter/tool version publishes a Capability Profile and evidence, so unsupported depth remains visible instead of coupling C1 to one CAD vendor.
