# Template Release 0.1.0

This is the first Template Release of the stack-neutral Development Workspace Template.

## Included baseline

- Core Workspace contract and public `./scripts/verify-template` verification.
- Portable Linux Dev Container guidance for local containers, Codespaces, and WSL2 fallback.
- Provider-neutral Agent collaboration with project-local skills and a GitHub Platform Adapter.
- Extension boundaries for a future application Stack Profile or Platform Adapter.

## Adoption

Generated Projects are independently owned after creation. There is no automatic synchronization, silent overwrite, or forced update from this template. Adopt this release intentionally by reviewing the migration guidance and the project-owned diff.

This release does not select an application Stack Profile, provision a Platform Adapter, require Azure, or add application lifecycle commands.
