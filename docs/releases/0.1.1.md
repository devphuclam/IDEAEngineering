# Template Release 0.1.1

This patch release refreshes the project-local agent workflow without changing the Core Workspace
or application/platform boundaries.

## Included updates

- Update the project-local Spec Kit integration and CLI baseline to `0.16.5`.
- Refresh the tracked Matt Pocock engineering skills from `mattpocock/skills`.
- Refresh the seven design skills, including UI/UX Pro Max, from
  `nextlevelbuilder/ui-ux-pro-max-skill`.
- Add `skills-lock.json` so future upstream skill updates have explicit source paths and content
  hashes.
- Preserve LF line endings for snapshot-backed UI/UX Pro Max catalogs on Windows.
- Keep the provider-neutral Agent Workspace and Azure live gates unchanged.

## Adoption

Generated Projects are independently owned. Review this release against project-owned skill edits,
then adopt it intentionally through the normal migration guidance. There is no automatic
synchronization. Preserve the Generated Project's `.template-provenance` origin record when
applying this release, including any project-owned Stack Profile or Platform Adapter changes.
