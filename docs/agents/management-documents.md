# Management-facing Word documents

Use this guide when creating, editing or comparing Word documents for the boss.

## Sources and editorial copies

Read the [IDEA instance catalogue](../product/instances/idea-engineering/README.md) to identify the
Feature, Spec or Tech brief, its detailed sources and the exact versions being presented.

The user's writing and layout references are in:

`C:/Users/TD-999/Research/Projects/IDEA/Human/IDEAEngineering`

This Human folder holds the user's editorial copies, not disposable exports. Compare actual
requirements, conditions and technology choices before reporting a baseline discrepancy. A
different filename, version label or writing style alone does not establish a discrepancy.

Preserve the user's originals. Produce a separately named copy for edits unless the user explicitly
asks to overwrite. If the reference folder or files are unavailable, ask for their current location.

## Writing

Write natural Vietnamese with concrete explanations and familiar engineering examples. Retain
common technical terms and explain unfamiliar terms on first use. Preserve exact requirements,
conditions and decision status while simplifying the wording.

Present recommendations directly to management. Keep agent workflow narration and repeated caveats
out of the main explanation; state meaningful limitations where they affect a decision.

## Layout and delivery

Use the supplied [horizontal IDEA logo](../../logo-idea.png) and preserve its aspect ratio.
Follow the user's cover-page and table-of-contents layout in the Human references.

Before delivery, update the table of contents and inspect the rendered pages for clipped text,
broken tables, misplaced images and unnecessary blank pages. Check that the delivered copy still
contains the intended requirements and decision status. Report any verification that could not
be completed; a successful file export alone is not a rendered-page check.
