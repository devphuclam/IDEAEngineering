## Summary & Verification

Taste Skill is an open-source anti-slop frontend framework for AI coding assistants. It enforces strict design disciplines to prevent generic AI frontend clichés:
1. Ban on AI-purple and mesh blob gradients.
2. Ban on three-equal-card feature rows by default.
3. Ban on em-dashes and en-dashes in UI copy.
4. WCAG AA contrast enforcement on form inputs, focus states, and interactive elements.
5. Consistent palette lock (1 accent, neutral industrial bases: Navy/Slate).
6. Strict layout and viewport stability rules.
