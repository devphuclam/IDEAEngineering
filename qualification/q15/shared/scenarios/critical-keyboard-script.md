# Q-15 frozen critical keyboard script

Status: proposed experiment acceptance control; **not an approved Product requirement**.

Run the same sequence on Option A Web, Option A installed shell, Option B Web, and
Option B Windows wherever the surface supports the action.

1. Focus the username field, enter `engineer`, and move to password using `Tab`.
2. Enter the synthetic password and activate **Sign in** without a pointer.
3. Tab to Search, enter `pump`, and submit.
4. Move result selection down/up, extend selection with the platform convention,
   and open the selected document.
5. Move focus between hierarchy and grid; expand/collapse one tree node.
6. Reach the permitted inline title editor, enter Vietnamese/Japanese fixture text,
   commit once and cancel once.
7. Open and close the context menu and return focus to its invoking row.
8. Navigate metadata and status without losing selected identity.
9. Invoke Checkout, then the typed Workspace Open action.
10. Return to the same operation and read Check-in status.

Capture unreachable actions, focus loss, traps, unexpected reset, and task
completion. The matrix's proposed target is 100% completion and zero focus traps;
authority approval of that threshold remains `BLOCKED`.
