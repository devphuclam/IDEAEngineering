# Development Workspace Template

This repository is a product-neutral Development Workspace Template for starting projects with consistent collaboration and verification conventions.

From a clean checkout, run:

```bash
./scripts/verify-template
```

Read the [Core Workspace contract](docs/core-workspace.md) for the supported V1 scope and clean-checkout verification, the [development environment guide](docs/development-environment.md) for local containers, Codespaces, WSL2 fallback, and Docker Desktop WSL recovery via `./scripts/docker-wsl-recovery.sh`, the [Generated Project onboarding](docs/generated-projects.md) guide for creating and intentionally extending projects, the [Spec Kit + Matt Pocock workflow](docs/agents/spec-kit.md) for specification-driven work, the [Template Releases](docs/releases/), the [migration guidance](docs/template-migrations.md), and the [Azure-ready Platform Adapter boundary](docs/platform-adapters/azure.md), plus the [project context](CONTEXT.md), [agent guidance](AGENTS.md), [example environment configuration](config/template.env.example), and [safe Azure adapter example configuration](config/azure-adapter.env.example). The source release is recorded in [.template-provenance](.template-provenance).
